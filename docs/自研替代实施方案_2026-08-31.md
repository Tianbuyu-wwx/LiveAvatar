## 2. R2' 库依赖瘦身

### 2.1 A1：自研 VAE 加载器（去 diffusers）—— feat(musetalk)

**目标**：`musetalk/models/vae.py` 不再 `from diffusers import AutoencoderKL`；extras 移除 diffusers。sd-vae-ft-mse **权重文件不变**。

**设计**（新文件 `src/liveavatar/musetalk/models/vae_kl.py`，~200 行）：
- `class DiagonalGaussianDistribution`: `sample()`（重参数化），对齐 `vae.encode(...).latent_dist` 用法；
- `class EncodeResult / DecodeResult`: 薄包装暴露 `.latent_dist` / `.sample`，**调用面零改动**（vae.py 的 `encode_latents/decode_latents` 一行不动）；
- `class AutoencoderKLCompat(nn.Module)`：SD-VAE 架构（Encoder/Decoder conv 栈，ch=128、ch_mult=(1,2,4,4)、attn 分辨率 16/8、z_channels=4）+ `quant_conv`/`post_quant_conv`（1×1 conv 8→4 / 4→8）；`encode()` 返回 `EncodeResult`，`decode()` 返回 `DecodeResult`；
- `AutoencoderKLCompat.from_pretrained_kl(path)`：读 `config.json`（`scaling_factor`、`block_out_channels` 等用于断言架构匹配）+ 权重（优先 `diffusion_pytorch_model.safetensors`，回退 `.bin`）；**diffusers key 前缀直映**（`encoder.*`/`decoder.*`/`quant_conv.*`/`post_quant_conv.*` 与自研命名一致，仅 `norm_out`/`mid_block` 命名核对）——用 `load_state_dict(strict=False)` 并**断言 missing_keys/unexpected_keys 均为空**，映射遗漏当场炸而非静默；
- vae.py 改一行 import + `AutoencoderKL.from_pretrained` → `AutoencoderKLCompat.from_pretrained_kl`。

**配套**：pyproject `inference` extras 移除 `"diffusers"`；**同时补 TTS 隐式依赖缺口**（0.2 节）：新增 `tts = ["torchaudio", "librosa", "fast_langdetect", "einops"]` optional extra（GPT-SoVITS 引擎专用），Dockerfile/README 同步——这解决了"voice 功能装包即缺件"的既有问题，属顺手修复。

**测试** `tests/test_vae_self.py`（全部 skipUnless(torch)）：
1. `test_key_mapping_lossless`：随机初始化 → 保存为 diffusers 命名 state_dict → `from_pretrained_kl` 加载 → 两次前向输出逐位相等；
2. `test_decode_shape_and_range`：随机 latents [1,4,32,32] → decode → [1,3,256,256]、uint8、值域 [0,255]；
3. `test_encode_decode_roundtrip`：encode→decode 非全零、方差合理（不比对 diffusers，纯 smoke）；
4. `test_against_diffusers_if_available`（仅本地）：若 diffusers 可导入，同 latents 两版 decode 输出 `allclose(atol=1)`（uint8 像素级 ≤1 灰度差）；CI 无 diffusers 自动 skip。

**风险**：key 映射遗漏（已用 strict 断言兜底）；`attn` 实现（SD-VAE 的 attention 用 `scaled_dot_product_attention` 即可对齐）。**回滚**：revert C4 即恢复 diffusers 路径。
**工作量**：2–4 天（含对齐调试）。

### 2.2 A2：自研 whisper-tiny encoder（去 musetalk 对 transformers 的使用）—— feat(musetalk)

**目标**：`musetalk/audio2feature.py` 不再 `from transformers import ...`。**明确边界**：transformers 在 extras **保留**（TTS 引擎必需），此项只消除口型管线对该库的依赖，为 R3 自研模型铺路。

**设计**（新文件 `src/liveavatar/musetalk/audio_encoder.py`，~250 行）：
- **特征器**：Whisper 约定 log-mel（16kHz、n_fft=400、hop=160、n_mels=80、峰值归一化 + clamp min -1e10、log10），纯 torch 实现（对齐 `AutoFeatureExtractor` 数值行为）；
- **Encoder**：whisper-tiny 结构——两层 Conv1d 前端（k=3、padding=1，通道 80→384→384，GELU）+ 可学习正弦位置编码（`embed_positions`，即 conv1d 权重）+ 4 层 pre-LN Transformer（d_model=384、8 heads、ffn=1536、GELU）；`forward` 返回 hidden states 列表（**先精读 audio2feature.py:160-170 确认现有 `self.whisper.encoder(...)` 的返回消费方式**，保持同构）；
- `WhisperTinyEncoder.from_pretrained(path)`：加载 HF whisper-tiny 目录中 encoder 相关权重（`model.encoder.*` 与 `model.encoder.embed_positions.*` key 映射），strict 断言同 A1。

**测试** `tests/test_audio_encoder.py`（skipUnless(torch)）：
1. `test_weight_load_strict`：dummy 权重 save→load，missing/unexpected 均空；
2. `test_feature_shapes`：1s 白噪声 → mel [1,80,100] → hidden states 逐层 [1,100,384]；
3. `test_against_transformers_if_available`（仅本地）：同输入对比 transformers WhisperModel encoder 输出 `allclose(atol=1e-4)`；且 `Audio2Feature.audio2feat` 最终特征矩阵两版一致（这是下游真正消费的量）；
4. `test_feature2chunks_unchanged`：`feature2chunks` 输出与替换前一致（固定输入回归）。

**风险**：conv1d 位置编码的 padding 语义、hidden state 裁剪（whisper 会丢最后 7 帧？——以实测对齐为准，对齐不上的可能性低但工时预留）；**回滚**：revert C5。
**工作量**：3–5 天。

### 2.4 A4：自研 RFC6455 WebSocket 客户端（可选）—— feat(audio_in)

**目标**：`audio_in/adapters/realtime_asr_client.py` 与测试不再依赖 `websockets` 库（服务端 WS 本就走 FastAPI/uvicorn，不受影响）。

**设计**（新文件 `src/liveavatar/_common/ws_client.py`，~400 行）：
- `async def connect(url, *, open_timeout=5.0, ping_interval=20.0)` → `WsClient`；
- 握手：HTTP/1.1 Upgrade、`Sec-WebSocket-Key` 生成 + `Sec-WebSocket-Accept` 校验（RFC6455 §4.2.2）、状态码 101 断言；
- 帧编解码：FIN/RSV/opcode、客户端强制 mask、`0x2` binary / `0x1` text / `0x8` close / `0x9` ping / `0xA` pong、控制帧 ≤125 字节校验、分片消息重组（continuation）；
- 生命周期：心跳协程（ping/pong 超时断连）、close 握手（先发 close 帧再等对端）、`recv()/send()/close()` 与 `websockets` 库接口同构（realtime_asr_client 零改动或仅改 import）；
- **首版仅支持 `ws://`**：wss/TLS 不做（内网 ASR 服务场景足够），docstring 明示。

**测试** `tests/test_ws_client.py`：
1. `test_echo_roundtrip`：对本地 uvicorn echo WS（测试内起，复用现有测试服务模式）收发文本/二进制；
2. `test_fragmented_message`：服务端发分片帧（raw socket 写手搓帧）→ 客户端重组正确；
3. `test_close_handshake`：服务端主动 close → 客户端 recv 抛 ConnectionClosed 等价异常；
4. `test_ping_pong`：客户端 ping → 收到 pong；
5. `test_asr_client_compat`：realtime_asr_client 换用自研客户端后，现有 `tests/audio_in/test_reconnect.py` 全绿（不改断言）。

**风险**：协议边角（扩展协商、status code）——首版拒绝任何 `Sec-WebSocket-Extensions` 响应（不带 permessage-deflate），杜绝压缩路径。**回滚**：revert C6；`websockets` 保留在 dev extras 直至确认稳定 2 个 minor 版本后再删。
**工作量**：2–3 天。

## 3. R3 指针（不在本方案）

R3 模型自训线（GPU）：R1 人脸训练工作流（docs/自研人脸检测与对齐方案_2026-08-31.md §M5）→ 口型模型自研（第二个 AvatarWorker）→ 远期 TTS 文本前端自研（不立项）。A1/A2 的自研加载器即 R3 的前置件：自研模型将直接消费 mel 特征与 latent 空间定义。

## 4. 一句话总结

R1' = 修 1 个实测 P0（3 个源文件从未入库）+ 4 件文档收尾，半天到一天；R2' = 用自研加载器把 musetalk 管线对 diffusers/transformers 的依赖剥离（transformers 的 extras 因 TTS 引擎保留），顺手补齐 TTS 隐式依赖 extra；全部 CPU 可验证、每项带测试、独立提交可回滚。
